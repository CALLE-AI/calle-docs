# CALL-E documentation examples

Use [`v2/`](v2/) for new integrations with `/v2/calls` and SDK 1.0.1.
The files directly in this directory use the legacy `/v1/calls` contract and
SDK 0.7.0, including `recover_create.py` and the result/transcript readers.
Keep their request shapes, IDs and recovery rules separate from V2.

See the [migration guide](https://docs.heycall-e.com/migration) before upgrading
an existing workflow.
